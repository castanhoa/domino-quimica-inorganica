Requisitos Funcionais:
    O sistema deve apresentar peças de dominó digitais contendo informações químicas (fórmulas, nomes, propriedades ou classificações).
    O jogo deve permitir que o aluno conecte peças somente quando houver correspondência conceitual correta.
    O sistema deve validar automaticamente as conexões realizadas pelo jogador.
    O jogo deve possuir níveis progressivos de dificuldade (ex.: inicialmente fórmula ↔ função, depois propriedades ↔ classificação).
    O sistema deve registrar tempo de partida e número de acertos/erros.
    O sistema deve possuir autenticação simples de usuários (aluno/professor) para permitir acompanhamento individual do desempenho.
    O sistema deve disponibilizar relatórios básicos de desempenho por aluno
 

Requisitos Não Funcionais:
    O sistema deve possuir interface intuitiva e adequada a estudantes do ensino médio.
    O jogo deve funcionar em computadores.
    O jogo deve armazenar dados de desempenho dos alunos para análise pedagógica.
    O software deve seguir boas práticas de acessibilidade (contraste, fontes legíveis, descrição de imagens).
    O sistema deve garantir privacidade e proteção dos dados dos alunos, conforme boas práticas de segurança e LGPD

Breve relatório com as principais informações obtidas no primeiro encontro com o parceiro:
•	Plataforma: Aplicação desktop
•	Modos de jogo: Fórmula/Conceito, Conceito/Propriedade, Propriedade/Fórmula
•	Deve haver diferenciação entre aluno e professor
•	Porcentagem de acertos quanto aos diferentes compostos
•	Diferentes modos de dificuldade, mudando a forma de associar os compostos inorgânicos
•	Usuários: Alunos do 2º ano do ensino médio da ETEC
•	1 jogador contra 1 robô (PvE)
•	Dificuldade aumenta progressivamente conforme o jogador vence
